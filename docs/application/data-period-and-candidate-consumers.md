# Data periods and local candidate consumers

This note documents the application-side read contract. The released v1 reader lock and artifacts remain immutable. Reader-v2 data require their own exact contract lock and admitted rows; local-review candidates are available only through an explicit loopback configuration and never become public data through this adapter.

## Unemployment period selection

The React state owner keeps one selected period shared by the map, values, source panel, comparison, and rankings. The default is annual average 2025; its native period is BLS M13 and it is never interpreted as January. Monthly selectors request one exact year/month using `/api/atlas/period-observations`; the 12-month place series uses `/api/atlas/unemployment-months`. Requests validate the response field, period type, year, month, native period, NSA identity, unit, source release, and fixed domain before values reach the map. Cache keys include the selected period, and request ownership prevents older responses from replacing a newer selection.

The released v1 unemployment field does not establish NSA identity, so the period adapter fails closed against v1. The reader-v2 consumer requires catalog 03.06 to declare `sourceCode=bls_laus`, `seasonalAdjustment=NSA`, and one exact `sourceRelease`; monthly and annual rows must share that release. Admitted mode reads only passed ingests and admitted reader batches. The chart draws observed January–December rows only. Missing months are blank, with no bar or fabricated zero. A fixed 2025 domain is computed from the maximum observed monthly rate across all mapped geographies in that release, starts at zero, and is shared by the map and chart. Out-of-range observations return an error rather than being clipped.

The chart is a bare monochrome 12-month scale. Month buttons support pointer, touch, focus, and keyboard activation; the selected month remains selected after focus leaves. Accessible labels include the month, year, and observed value or no-data state. The visible caption is “Monthly chart” plus a selected month when applicable, with an annual-average control. The y-axis labels show the shared upper percentage and zero baseline.

## Shared race selector and candidate catalog

The race selector is a single shared group: Hispanic or Latino, White, Black, Asian, and the broad American Indian and Alaska Native alone-or-in-combination measure. The AIAN app mapping is catalog 01.04, field `01.04:aian_share`, dataset `aian_broad_share`, and ACS 2024 5-year release. Its broad category includes Hispanic/Latino residents and can overlap other race measures. Estimate, source MOE, denominator, denominator MOE, period, geography, and provenance stay attached to each observation; no derived share MOE is claimed.

The local candidate catalog reserves 12.01 President, 12.02 Senate, and 12.03 House. The app maps producer dataset IDs to these consumer IDs explicitly. Election requests currently select the 2024 cycle and a party. President results map to counties, Senate to states, and House to 2024 CD119 / Congress 119 districts, including at-large 00 and excluding nonvoting 98. Candidate votes divided by the contest total are returned as percentage points on a 0–100 domain. The response retains candidate identity, source vote strings, raw party, normalized party, selected party, contest, source stage, special/runoff flags, result mode, source release/version, and geography mapping state. The API rejects multiple contest identities for one displayed place. A validated party-result row is required for a numeric value; an absent party row is missing, while an explicit validated zero remains zero. `no_election`, missing, suppressed, invalid, and nonmapping results remain null with distinct quality states.

Reader-v2 endpoints are read-only. An explicitly configured local-review mode requires loopback access and reports `candidate_nonreleased`; admitted mode requires the pinned v2 contract, passed ingests, and admitted reader batches. Candidate availability alone is not release admission. The app does not bundle source collection files, credentials, or the local congressional boundary.

PostgreSQL CI applies the frozen v2 schema and consumer fixture, then promotes only that synthetic fixture batch through an app-owned CI SQL file. Its adapter checks run in admitted mode with the read-only role, alongside the unchanged v1 schema and contract checks. This verifies the production query/filter path; the fixture is not collected or release data.

## Rate and selection metadata

Selection counts come from the current selectable registry. Income total and per-resident remain two modes of one selection. The recreation/fitness source remains retained but hidden from primary map choices. The current expected candidate-aware count is 41 primary selections and four additional race variants (45 total); a missing candidate stays visible with an accurate unavailable status rather than changing the count.

The AGI per-resident mode uses 2023 IRS SOI income divided by the annual 2023 Census PEP total population, with units stated as USD per resident and persons. Cancer is a custom 2023 rate using the 2023 PEP total population. HIV is a provisional custom 2024 rate using 2024 PEP age 13+ population. Under-18 mortality is a custom 2024 rate using 2024 PEP under-18 population. These have different event years, denominator years, and population kinds; source details identify each numerator, denominator, unit, and formula. Updated official FBI results use the 2025 annual SRS population reported with each offense record, not an ACS denominator or summed monthly reports. Source details show rate construction on desktop and mobile.

The PEP consumer mappings are confirmed by the prepared reader input mapping. Native national PEP totals are verified from the official national single-age source. The refreshed reader carries native U.S. values only when the numerator source itself supplies a national count: cancer and IRS have verified native U.S. rows; HIV and child-death candidate outputs remain missing at U.S. level because their retained numerator inputs are state-only. The app does not sum states to invent a national numerator. Candidate data remain local and nonreleased; if an exact candidate field, period, unit, geography, or approved source release is unavailable, the app fails closed without substituting an older ACS-derived value.

The official annual 2025 FBI SRS workbook has been verified and prepared as seven same-record rates from its annual offense counts and reported population. The app maps catalog fields `04.01:derived` through `04.07:derived`, each for annual 2025 and per 100,000. Field 04.07 uses the revised rape estimate. These values are not synthesized from monthly reports or calculated with ACS population. The candidate FBI rows have not yet been loaded into the reviewed reader database, so those selectors remain unavailable; the app does not relabel the older FBI series as 2025.
