# Local UI assets

- **Brand 02 icons:** 16 original PNGs copied byte-for-byte from the owner's accepted `design/brand-icons-v3/png/` library on 2026-10-08. These are owner-provided design assets, with generation provenance in that library's `generation.json`; no third-party icon package or runtime dependency is introduced. Original white/black pixels remain intact. `ux/icons.js` uses the library's `evidence/ink-bounds.json` crop and an SVG display filter to render the symbol in the surrounding control's text color.
- **Geist 400/500/600/700:** reused from `design/paper-synthesis-106/assets/`; SIL Open Font License, accompanying `Geist-OFL.txt`. Served locally, with no external font request.
