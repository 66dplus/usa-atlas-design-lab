# Cryptocurrency network logos

The six monochrome SVG logos are bundled locally and shown as decorative CSS masks.

- Bitcoin, Ethereum, Solana, BNB Chain and Polygon: Simple Icons, pinned to commit `90646e4bf7f3b89df6c37e65baf3e7bc759a517c`, CC0 1.0 Universal. Source paths: `icons/{bitcoin,ethereum,solana,bnbchain,polygon}.svg`.
- TRON: spothq/cryptocurrency-icons, pinned to commit `1a63530be6e374711a8554f31b17e4cb92c25fa5`, CC0 1.0 Universal. Source path: `svg/black/trx.svg`.

Brand names and marks remain the property of their respective owners. These are identifiers for supported networks, not endorsements. The public preview packager explicitly includes only these six SVG files; this note stays in the source repository.
